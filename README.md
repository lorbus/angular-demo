# Demo App for Video Courses and Lessons

## 1. Installation pre-requisites
- Angular version >= 18.x.x
- Node version >= 23 - long-term support (LTS) version
- Use NPM version >= 5


## 2. Installing
`npm install`


## 3. Run the App (using the Angular CLI)

1. Run BE with the following command:
`npm run server`

2. To run the FE with the following command:
`npm start`


Go to App: [http://localhost:4200](http://localhost:4200)
